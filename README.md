# 金宋当铺

《Probably Stolen》的金宋题材 MOD。项目为当铺、人物、商品、界面、地点和对白换装，并加入宋国侠士沈砺的独立任务线。净水、蓄能、机巧加工、买卖和原版任务沿用游戏的原生规则。

当前源码对应 **0.1.2-alpha262**，面向《Probably Stolen》Steam 版，清单声明的游戏版本为 **0.46D**。物品详情 0.9.4 的兼容接入已有实机记录。
