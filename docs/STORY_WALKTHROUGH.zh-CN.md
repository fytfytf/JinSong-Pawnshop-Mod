# 金宋当铺新增剧情攻略

适用版本 **0.1.2-alpha277**。本文含完整剧透，覆盖沈砺的人物结局与《城门将晓》的三种城市结局。两条线都在普通经营局触发，无尽模式不安排这些来访。原版顾客与已排队的剧情可能占用来访时段，攻略里的最早日期以实际完成前置事件为准。

## 交易与文书

- 对话里报出的开场预算或这批货的总报价是分母。该顾客**本次来访**中符合要求的实际成交金额合计达到 **66%** 即达标，刚好达到也算。议价后的实付金额才计入。货摆上桌、查看报价、按归仓箭头都不算成交。
- 交易结果在顾客离窗时结算。确认金额够了再送客。举例，预算 1000 要成交至少 660，预算 500 要成交至少 330。
- 领文书或等供应商来时，给柜台留出空格。收下后把原件存入自有库存。要把同一张文书交给谁，在相应来访的对白里选。交付会收走原件。

## 沈砺

| 顺序 | 触发 | 做法与影响 |
| --- | --- | --- |
| 1. 买口粮 | 第 17 天起，行脚商人来访 | 卖给他至少 **660／1000** 的食物。达标时，他下次带三件军需配件来卖，未达标时带一件。 |
| 2. 领通缉单 | 买口粮离窗后的次日 | 金军守兵送来独立文书「金军军营通缉单」。柜台放不下时腾格等他再来。 |
| 3. 销赃 | 通缉单成功送达后的下一营业日起 | 买下沈砺带来、价值达到开场总报价 **66%** 的军需配件。他因此打听到军需官的行程。 |
| 4. 购武 | 销赃离窗满 **3 天** | 选「继续做买卖」，卖给他至少 **660／1000** 的武器。达标时军需官身亡，未达时军需官生还。也可以在这次对白选「向金军举报」，让沈砺在行刺前被捕。 |
| 5. 求药 | 购武离窗后的次日，且此前未举报 | 卖给他至少 **330／500** 的伤药或绷带。达标时沈砺逃出城，未达时被捕。麻醉品不计入。 |

口粮和销赃改变他后续带来的货和对白。军需官生死由购武成交额决定，沈砺能否出城由求药成交额决定。结局在判定后的次日刊入每日新闻。

| 想看的结局 | 购武 | 求药 |
| --- | --- | --- |
| 军需官身亡，沈砺出城 | ≥660 | ≥330 |
| 军需官身亡，沈砺被捕 | ≥660 | <330 |
| 军需官生还，沈砺出城 | <660 | ≥330 |
| 军需官生还，沈砺被捕 | <660 | <330 |
| 沈砺在行刺前被捕 | 选择「向金军举报」 | 本次来访锁定结局 |

## 城门将晓

### 第 7 天起的军需买卖

1. 周砚第一次来访时选「收下两份帖子」，拿到「粮仓接洽帖」和「武库接洽帖」。两份都成功送达后，才开始计算供货间隔。拒绝接洽会关闭战前筹备，围城仍按日程发生。
2. 两帖齐后满 **4 天**，郭守义来卖纸包粟饼。郭守义离窗满 **4 天**，石五来卖军用短刃和军用砍刀。每批在本次来访中买到开场报价的 **66%**，该批使金方 **−2**。想帮巡检司收回军需时，把实际买下的这批原货单独留存。
3. 石五离窗满 **3 天**，周砚来收粮。收粮离窗满 **4 天**，周砚再来收军械。分别按该次预算卖到 **66%**，每次宋方 **+2**。他收符合类别的口粮或武器。五次来访在完全未顺延时最早是第 **7、11、15、18、22** 天。

### 战前人物和关键文书

收粮、收械结束后按事件进度排后续来访。下表列出每位人物能帮你达成的条件。

| 人物与来访 | 要做什么 | 结果或文书 |
| --- | --- | --- |
| 石五再来 | 「付四十文，收下军械收据」 | 拿「武库收据」。这次付钱会留下石五可以作证的事实。 |
| 郭守义再来 | 答应照看家人，或给 **30** 文安家钱 | 巡检查问时郭守义会作证。想避免这条供词时选「这件事我先不接」。 |
| 韩成求粮 | 卖至少 **119／180** 的食物 | 韩成吃到粮，后面才肯接受主将的承诺。此时先记达标，接应尚未成立。 |
| 许承赎当 | 「收下许承的仓簿残页」 | 得到「旧仓簿残页」。原件可交周砚、完颜素或蒲察安，只能选一处。 |
| 杜九替魏简求药 | 卖至少 **99／150** 的伤药或绷带 | 魏简回访确认会合后，城外接应成立，宋方 **+3**。 |
| 周砚送承诺书 | 「收下宋军主将的承诺书」 | 若还想把仓簿留给完颜素或巡检司，选只收承诺书的选项。 |
| 韩成再来 | 已喂饱手下，选「递上宋军主将的承诺书」 | 韩成明确答应接应，宋方 **+3**，另得「城门值守名册」。只请他留名册也能拿到文书，韩成仍未答应开门。 |
| 魏简回访 | 收下「城外传令帖」可留作证据 | 战前求药达标时，这次来访确认城外会合。让魏简带走帖子也可确认会合。 |
| 完颜素索账 | 「把仓簿交给完颜素」 | 他退回征粮令，金方 **−2**，给「仓行通帖」。交给巡检司的路线需保留仓簿原件。 |
| 魏简替补 | 韩成未接应、魏简已会合时，选「替魏简给巡夜队传话」 | 可另获城内接应，宋方 **+2**。 |

### 围城和巡检查验

- **第 42 天**日报预告封门，**第 43 天清晨**固定围城。筹备进度和点数只影响围城后的结局。封城后战前来访结束，已经完成的交易和选择仍有效。
- 韩成和周砚争同一批粮，选留给其中一人，等他另日上门再成交。粮款至少 **208／315**，达标使宋方 **+2**。若选周砚并达标，还可作为城外接应的另一条来源。
- 完颜素征粮和石五盘库只收原批军需。预算为开场总报价和 **80** 两者中的较高值，仍以 **66%** 成交额离窗判定。此前进货已经扣分的批次被追回后，金方各恢复 **+2**。完颜素已退回征粮令时，军粮不会走这次征回交易。
- 围城期间，争粮取货和征回军粮的合格口粮议定价 **×1.75**，杜九围城求药的伤药 **×1.50**。杜九这次至少收 **149／225** 才达标。这笔药是围城中的街坊委托，战前那次药才用于魏简会合。普通顾客的商品价格照常。
- 想加入协查，满足任一条件后等蒲察安来访并答应。条件为 **两名不同通缉犯的成功举报**、**一名成功举报且巡检司声望为正**，或**持有旧仓簿残页／武库收据**。原版举报须走到成功结算，重复举报同一人不增加次数。

### 三环证据与掌柜案情

| 协查环节 | 交给蒲察安的原件 | 同一案的印证 |
| --- | --- | --- |
| 供货 · 军粮 | 旧仓簿残页 | 郭守义此前答应作证 |
| 供货 · 军械 | 武库收据 | 此前付石五四十文取得收据 |
| 城内接应 | 城门值守名册 | 韩成的答复来访已完成 |
| 城外联络 | 城外传令帖 | 魏简的回访已完成 |

每份有效书证使金方 **+2**，同案得到印证再 **+2**。军粮和军械可分案计分，终局都归到供货这一环。蒲察安查验时，掌柜若已涉入某批供货，该批有追回的原货或对应的证人，巡检也能完成该案的互证。查验坐实城内、城外接应时，会撤掉宋方已取得的对应接应点数。

协查中确认至少两环，且掌柜本人仍有互证成立的涉案事项时，留意「交代我经手的货与传过的话」。这项对白会处理**当时已互证**的自身案情。之后若再补出一项涉案证据，要在裁定前再把该案交代清楚。

### 三种城市结局

宋方初始 **0**，金方初始 **6**。点数在游戏里隐藏。三种结局都要等围城开始、蒲察安的查验对白完成，再由最后一位来访者落定。

| 结局 | 必要条件 | 落定后 |
| --- | --- | --- |
| 宋军收复城市 | 宋方 **≥8**，金方 **≤4**，城内、城外接应都有效 | 周砚报信，展示宋军入城插画。次晨挂宋旗、刊报、领「宋军复市令」，可继续营业。 |
| 巡检司嘉奖 | 金方 **≥8**，已受托协查，供货、城内、城外三环查实，掌柜自身案情已处理 | 蒲察安宣告结案。次晨窗边挂「完颜特许」旗，领取「巡检司嘉奖书」，可继续营业。 |
| 金国府衙处刑 | 金方 **≥8**，掌柜参与的行为已有书证和供词互证，而且该案未在协查中处理 | 蒲察安送「府衙处刑判牍」并拘捕掌柜，进入处刑界面，本局结束。给判牍留柜台空格。 |

仍有符合处刑条件的未处理案情时，拘捕优先。没有满足任一结局条件时，可以继续营业。结局日期取决于来访和查验进度。

### 三套走法

**宋军入城。** 接两帖，两批军需都买够，周砚两次收货都卖够。韩成求粮达标，收周砚承诺书并交给韩成。杜九战前求药达标，等魏简回访确认会合。保留仓簿给完颜素退征粮令，围城争粮时选周砚，等他实际来收粮再卖够。不接受巡检协查，查验时走完对白。若付石五四十文拿过收据，尽量别再让郭守义作证，避免两批供货同时被坐实。实机路线第 **58 天**落定，宋 **12**、金 **4**，第 **59 天**拿复市令。

**巡检司嘉奖。** 接两帖，两批都买够，原批军粮和军械留着，周砚来收货时不交给他。付石五四十文，答应照看郭守义家人，向许承拿仓簿。韩成处选只留值守名册，魏简回访收传令帖，仓簿不交完颜素。答应蒲察安协查。围城争粮时两边都不留，按两次征回委托交回原批货并达标。协查来访依次交仓簿、值守名册、传令帖，配合查验。等蒲察安再来时选「交代我经手的货与传过的话」，把两笔供货案都处理掉。实机路线第 **64 天**落定，宋 **0**、金 **22**，第 **65 天**拿嘉奖书。

**掌柜被处刑。** 接两帖，两批军需买够，再按周砚两次预算卖够。付石五四十文，答应照看郭守义家人，让两案具备证人。其余接应不做，拒绝蒲察安协查，围城争粮两边都不留。等蒲察安查验，两批供货在案且掌柜未交代，随后收到处刑判牍。实机路线第 **56 天**落定，宋 **4**、金 **10**。

仓簿、收据、名册和传令帖都可能决定后续分支。想比较不同结局，可以在接受周砚接洽前另存一份进度，并在围城前再留一份。
