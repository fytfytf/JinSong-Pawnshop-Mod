# 电源与充电链

Alpha47按D1将8个原版注册对象表现为机巧蓄能器具。31张内置image_gen原图及逐项提示词/参考/导出回执在assets/v01/alpha47-power/；普通、扩容、自充的变体只引用自己的AI原图，不使用原游戏图片。tools/export_power_batch.py按alpha>=128的主体共同边界导出同族帧，保留原alpha/比例、最近邻缩放；31张导出可重现。原版主图/附层尺寸和pivot/PPU保持，实际游戏仍用原Sprite路径作状态索引。

| 原ID | 当前显示 | 原规则 |
|---|---|---|
| energy_credit | 铜扣蓄能匣 | 容量100，带宽10，可充 |
| energy_credit_ext | 扩容蓄能匣 | 容量250，带宽10，可充 |
| energy_credit_breeder | 自蓄能匣 | 容量100，带宽4，early周期自行+4；可充 |
| energy_credit_dis | 一次封装蓄能匣 | 容量1000，带宽10，禁止再充；耗尽保留原对象 |
| energy_credit_hyp | 奇巧供能匣 | 特殊输出12；不是2500容量，也不扣普通储能 |
| current_converter | 引能转换匣 | 外电付费供能、开关两态；不属普通电池 |
| recharger | 蓄能机巧台 | 原4×2内仓，普通/商业每周期+3/+6 |
| powerblock | 邻位蓄能台 | 原生相邻对象，普通/商业early+2/+4 |

前三族均覆盖100/80/60/40/20/10/0七个图，原阈值90/70/50/30/10/1不变。一次封装原版仅此链确认的battery_dis100，耗尽也不创建不存在的dis0；必须同时看剩余能量数值。转换匣两态、邻位台两态均沿原开关/供电规则。特殊供能匣图不画伪造百分比。原能量/带宽单位kJ/kW沿用，不做现实换算。

充电台的顶盖、灯和仓内电源图绕过子物品Resolve。UpdateInnateModSprite前缀只处理原充电台ID/atlas、原Sprite引用及已登记子项，复用现有图片缓存。原方法继续写真/假Image及位置/比例，不改回调或内仓。顶盖与双灯另3张附层，不混计为107条主图规则。开电时按原能量>=上限选绿灯，否则橙灯；关电不加灯。灯色不能证明本周期实际充入，停电拦截由原充电函数决定。

物件侧与仓侧条件都检查。一次封装在仓侧被拒；奇巧供能匣和引能转换匣虽然有电源标签，但自身mayInventoryAddItemFunc拒绝父ID=recharger，空仓也一样。早期准备报告漏查物件门，已撤回“可能装入”及其灯色推断，增加空仓拒装检查；不通过改原版规则让画面夹具硬塞进去。满仓截图用普通/扩容/自充/普通四件，特殊供能器独立库存显示。

功能检查区分层次：先在Alpha46原版图片下通过328项基线，再在Alpha47强制比较主题主图、fake图及真实innate图纹理，首次383项通过。完整夜专项首次210项通过，两次真实EndDay/EndNight覆盖普通及商业供电条件，观察early→normal→late与一次服务发票。确认相邻后分别测试单回调和完整夜；实际有冰酪的冰箱按原功耗扣能，自充仅一次+4，不把Unused家具路径算成正常双充。

停电测试换独立StoreEventManager，再用原停电事件工厂，退出恢复原引用；商业/偷电为复制字典中的已解锁条件夹具，不是购买过程。相邻窗口接临时载体以进入owned遍历是图结构夹具，不声称普通电池在玩家玩法中有容器。服务/升级/事件原对象不改；测试建立的引用和字段finally恢复。真实整夜的健康、统计、NightLog等自然副作用仅留在被守卫的临时内存店铺，不声称将整个夜晚事务回滚；从未用于现有档。

引能转换匣白天按实际折扣/取整费率扣款，余额不足拒绝；夜间由活动服务一次计费，普通储能始终0。没有给它添加免费电池语义，也没有让奇巧匣走普通充电。充电仓标题改为蓄能匣，一次封装不可充的硬编码原提示仅做中文替换，英文沿原文。

画面探针将高/低/空电量实际放入原仓库，查看主图及充电台多内件/顶盖/灯，打开真实内仓；窗口为审阅移到屏内，不代表已做真实鼠标拖放。通用窗体的进一步美术统一仍属5.4。所有截图实际2560×1440，其他分辨率不作通过声明。

基础游戏没有统一“可用N天”字段。当前已加载的物品详情为0.9.0：其普通电源行按当前能量除当前负载取整数，不预测自充；Converter/Hypertech排除普通能量/天数行。168项通过公开GetTooltipAdvanced验证普通满/低/空、扩容换装、自充、一次性和两种特殊来源，并跨缓存期限采样；20/100kJ、耗能2/天显示10天的实机截图已审阅。历史Alpha43/45的0.8.6结果保留原版范围。
